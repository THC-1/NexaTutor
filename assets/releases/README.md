# DeepTutor 上游历史发布记录

本目录保存 NexaTutor 技术底座 DeepTutor 的历史发布说明，用于：

- 追溯基线来源。
- 查找上游安全修复、严重 Bug 修复和兼容性变化。
- 判断某项旧数据或旧配置来自哪个版本。
- 为选择性 cherry-pick 或手动移植提供背景。

这些历史文件保持发布时的原始语言、产品名、链接和功能描述，不代表 NexaTutor 当前功能，也不应作为 NexaTutor 的安装或使用指南。

NexaTutor 当前状态以仓库根目录 [README](../../README.md)、[正式裁剪计划](../../NEXATUTOR_SLIMMING_PLAN_REVISED新版.md) 和[运行时基线](../../NEXATUTOR_RUNTIME_BASELINE.md)为准。

历史记录不得因品牌替换而机械改名；如需删除整个归档，必须作为独立批次评估来源追溯和许可证影响。
